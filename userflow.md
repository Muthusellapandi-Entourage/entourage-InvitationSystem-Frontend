# Entourage — User flows for Lucidchart

Two flowcharts. Draw them on two pages in one Lucidchart document.

Standard flowchart shapes:

| Meaning | Lucidchart shape |
| --- | --- |
| Start or end | Terminator (pill) |
| Screen or action | Process (rectangle) |
| Question | Decision (diamond) |
| Note | Callout, not on the main path |

Connect shapes in the order of the numbered steps. Put the step’s **Text** inside the shape. Put the **Arrow** text on the line that leaves that shape. Decision diamonds have two leaving arrows; both labels are listed.

## Page 1 — Organizer builds an invitation

Page name: `Organizer flow`.

Start at the top. Keep the five designer steps in one vertical column so the wizard reads as a sequence. Branch **Preview** and **Save draft** to the right of Review.

| Step | Shape | Text | Arrow to next |
| --- | --- | --- | --- |
| 1 | Terminator | Start | |
| 2 | Process | Open Entourage | |
| 3 | Decision | Already signed in? | Yes → 5. No → 4 |
| 4 | Process | Sign in with email and password | JWT stored, go to 5 |
| 5 | Process | Events list | |
| 6 | Decision | Event exists? | Yes → 8. No → 7 |
| 7 | Process | Create event (name, dates, timezone, slug) | |
| 8 | Process | Open Invitation builder | Loads saved template, or defaults |
| 9 | Process | Step 1 Artwork — upload header image | |
| 10 | Process | Choose placement: Fit width, Centered, or Original size | Original size is unavailable when the image is wider than the canvas |
| 11 | Process | Optional: canvas size, background color, position and size | |
| 12 | Process | Step 2 Guest details — greeting style, sample name, text alignment | |
| 13 | Process | Step 3 Event details — upload details image, fit, spacing | |
| 14 | Process | Step 4 RSVP — accept and decline images, order, size | |
| 15 | Process | Step 5 Review — check the canvas | |
| 16 | Decision | What next? | Preview → 17. Save draft → 19. Back → 9–14 |
| 17 | Process | Preview builds a temporary public link | Does not write the template |
| 18 | Process | Open guest preview | Link expires. Return to 15 |
| 19 | Process | Save draft | API validates design, stores DesignJson, rebuilds Html |
| 20 | Decision | Save succeeded? | Yes → 21. No → 15, show error |
| 21 | Terminator | Template saved | Guest link is /invite/{slug} |

Callouts (place beside the step, no arrow):

- Beside step 10: “Fit width spans the canvas. Centered is narrower and centered. Original size uses the file’s pixel width only when it fits.”
- Beside step 11: “Canvas background is the invitation fill, not the workspace. Transparent is allowed. Default for old templates is #313131.”
- Beside step 17: “Preview HTML is generated by the API and cached in memory.”

## Page 2 — Guest replies

Page name: `Guest flow`.

This page is public. No login diamond.

| Step | Shape | Text | Arrow to next |
| --- | --- | --- | --- |
| 1 | Terminator | Start | |
| 2 | Process | Open /invite/{slug} | |
| 3 | Decision | Template published? | Yes → 4. No → 5 |
| 4 | Process | See the saved email HTML | Images load from /api/public/assets/{id} |
| 5 | Terminator | Invitation is not available | End |
| 6 | Decision | Guest choice | Accept → 7. Decline → 8 |
| 7 | Process | Open /invite/{slug}/rsvp?status=accept | |
| 8 | Process | Open /invite/{slug}/rsvp?status=decline | |
| 9 | Process | Confirm the reply | Both 7 and 8 lead here |
| 10 | Process | POST /api/public/invitations/{slug}/responses | |
| 11 | Decision | Recorded? | Yes → 12. No → 13 |
| 12 | Process | Confirmation page | |
| 13 | Process | Show the error | Guest can retry from 6 |
| 14 | Terminator | End | |

`{{GuestName}}` and `{{GuestPosition}}` are placeholders in the saved HTML. The designer preview fills them with sample text (Sara Ahmed / Senior Manager). A real send would replace them per guest. Sending email is not part of this flow.

## Suggested layout

**Organizer flow**

```
Start → Signed in? → Events → Event exists? → Builder
                                      ↓ no
                                 Create event
Builder → Artwork → Guest → Event details → RSVP → Review
Review → Preview → temporary link → back to Review
Review → Save draft → saved?
```

**Guest flow**

```
Start → Open link → Published?
   no → Not available
   yes → Invitation → Accept or Decline → Confirm → Recorded? → Confirmation
```
